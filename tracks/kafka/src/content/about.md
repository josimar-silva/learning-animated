Kafka: The Definitive Guide Animated is a visual companion to [Kafka: The Definitive Guide, 2nd Edition](https://www.confluent.io/resources/ebook/kafka-the-definitive-guide/). Each animation brings one figure or idea from the book to life, so a diagram you read on the page becomes a system you can watch move.

## How to use it

1. Open the book at the chapter you are reading.
2. Note the number of the figure in front of you, then open the matching animation from the [contents](/).
3. Play, pause, and restart it. The "What to notice" note names the idea the motion makes clear.

## How it is built

Built with hand-authored SVG and SMIL. Every page is rendered to static HTML at build time, and every animation is a single self-contained SVG file that also plays on its own.
