# Attribution

## About this project

**Kafka: The Definitive Guide Animated** is an unofficial, fan-made learning
companion. It animates concepts from the book so a reader can watch each idea move.
The animations are original work; the ideas they illustrate belong to the book and
its authors.

This project is **not affiliated with, authorized by, or endorsed by** the authors,
O'Reilly Media, Confluent, or the Apache Software Foundation.

## The book

The concepts animated here are drawn from:

> **Kafka: The Definitive Guide, 2nd Edition**
> by Gwen Shapira, Todd Palino, Rajini Sivaram, and Krit Petty.
> Published by O'Reilly Media, 2021.

The publisher offers the book as a free ebook, sponsored by Confluent:
<https://www.confluent.io/resources/ebook/kafka-the-definitive-guide/>

Please read the book. This companion is meant to sit beside it, not replace it. Each
animation notes the chapter whose concepts it illustrates.
